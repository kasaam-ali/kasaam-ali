## 👨‍💻 About Me

🎓 **BS Artificial Intelligence** student, training intensively at **Saylani Mass IT (SMIT)**, Karachi 🇵🇰

🤖 I specialize in **Machine Learning**, **Deep Learning**, and **Computer Vision** — building production-ready systems from classification models to ANPR and facial recognition

🧠 **Recent Work:**
- **DaleelAI** — AI-powered tax & compliance assistant for Pakistan (FastAPI + PostgreSQL)
- **Movie Recommender System** — Content-based and collaborative filtering engine
- **Deep Learning Projects** — ANN, CNN, and transfer learning implementations
- **Smart City ANPR** — Automatic Number Plate Recognition with real-time detection

🌐 Full-stack AI development with **TypeScript, JavaScript, React**, and modern web technologies

📜 **Certifications:** 17+ credentials in AI Engineering, Generative AI, and Machine Learning

💡 Philosophy: Quality > Quantity. Building in public, learning by shipping real projects.
